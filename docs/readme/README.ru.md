# Jiumi 揪咪

Узнайте, что приложения делают на переднем плане и в фоне, и решите: оставить, ограничить, отключить или удалить их.
<br>Root-доступ и компьютер не нужны. Записи хранятся на телефоне.

## Возможности

### Понять активность

| Возможность | Что можно сделать |
| --- | --- |
| Обзор активности | Смотрите общее число, динамику, среднее, пик и фоновые обращения за **сеанс, сегодня, 7 или 30 дней**. Нажмите на график или проведите по нему, чтобы увидеть отдельный интервал. Интервалы без мониторинга и записей отмечены как **No records**. |
| Активность, требующая внимания | Находите на **тепловой карте** заметные дни и часы и просматривайте отправку данных и чувствительную активность в фоне, повторные чтения и повторные попытки после отказа. |
| Рейтинг приложений | Находите самые активные приложения по всем или фоновым обращениям и сравнивайте затронутые данные. Рутинная работа системы свёрнута отдельно. |
| Сведения о приложении | Следите за одним приложением на таком же графике. Нажмите на тип данных, чтобы оставить в графике и хронологии только его. |
| Записи об активности | Просматривайте **56 типов доступа в 12 группах**, включая местоположение, буфер обмена и идентификаторы устройства. Записи можно просматривать по времени, приложению или типу и отфильтровывать по фоновой активности. |
| Сетевая активность | Просматривайте адреса соединений и доступные показатели трафика по приложениям. Если включена запись доменов, у соединений, которые удалось сопоставить с доменом, может отображаться его имя. |
| История системы | Откройте сведения о приложении, чтобы посмотреть записи об использовании разрешений и общее число таких обращений, сохранённые Android. Доступна и часть активности до начала мониторинга. |

### Мониторинг и записи

| Возможность | Что можно сделать |
| --- | --- |
| Список исключений из мониторинга | Выберите приложения, за которыми не нужно следить, в **Settings › Monitoring › Monitoring allowlist**. Jiumi не создаёт для них новых записей и скрывает сохранённые. После исключения из списка они снова видны. Активность за пропущенный период не восстанавливается. |
| Уведомления | Во время мониторинга уведомление показывает длительность сеанса и кнопку остановки. Его можно отключить в **Settings › Notifications**. С **Show summary** оно показывает **число обращений за сеанс и сколько из них было в фоне**, без названий приложений. С **Attention alerts** приложение сообщит о новых событиях, требующих внимания, один раз для каждого приложения и вида события за сеанс. |
| Экспорт журнала | В **Settings › Logs › Export logs** можно сохранить записи за выбранный период в ZIP-архиве с файлами CSV. |

## Управление приложениями

Приложения сгруппированы по источнику установки. Откройте сведения о приложении, чтобы изучить его активность и решить, нужно ли что-либо менять. Действия по управлению запускаете вы. После каждого изменения Jiumi перечитывает состояние из Android, чтобы проверить, применилось ли оно. Если Android отклоняет изменение, Jiumi показывает причину.

  <a href="../images/app-delete.en.png"><img src="../images/app-delete.en.png" width="250" alt="Демонстрация подтверждения удаления приложения и уведомления о резервной копии на сайте" /></a>&nbsp;
  <a href="../images/app-restore.en.png"><img src="../images/app-restore.en.png" width="250" alt="Демонстрация восстановления удалённого приложения и удаления резервной копии на сайте" /></a>
</p>

| Действие | Результат |
| --- | --- |
| Разрешения | Включайте и отключайте разрешения по одному в разделе **Permissions** в сведениях о приложении. Переключатель **Manageable permissions** позволяет отключить сразу все управляемые разрешения. При повторном включении восстанавливаются только те разрешения, которые отключил Jiumi. Разрешения, заблокированные системой, доступны только для чтения. |
| Доступ к сети | На поддерживаемых устройствах можно блокировать и восстанавливать доступ отдельного приложения к сети через встроенный межсетевой экран Android, не занимая слот VPN. Переключатель блокируется с указанием причины, если приложение делит UID с другими приложениями, правило настроено другим инструментом или Jiumi не может подтвердить, что действие затронет только это приложение. |
| Отключить или включить приложение | Android отключает приложение для текущего пользователя. Приложение и его данные сохраняются. Включить приложение снова можно в **Apps › Disabled**. Отключённые приложения отмечены значком снежинки. |
| Снова включено | Если Jiumi обнаружит, что отключённое им приложение снова включено, в списке и сведениях появится отметка **Re-enabled**. В хронологии сохранится время обнаружения. Включите **Settings › App management › Disable again when re-enabled**, чтобы Jiumi снова отключал приложение. |
| Удалить установленное вами приложение | Введите полное имя пакета для подтверждения. Jiumi сохраняет основной APK и дополнительные APK, если они есть. Попробовать установить приложение снова можно в **Apps › Uninstalled**. **При удалении данные приложения стираются. Резервная копия содержит только установочные файлы.** |
| Удалить предустановленное приложение | Включите **Allow uninstalling preinstalled apps** в **Settings › App management**, чтобы удалять поддерживаемые предустановленные приложения для текущего пользователя. Заводская копия и данные приложения сохраняются. Попробовать восстановить приложение можно в **Apps › Uninstalled**. Удалённые приложения отмечены значком корзины. Если параметр выключен, нажатие **Uninstall** поясняет это и ведёт в **App management**. |

В разделе **Settings › App management** поле **Runs as** показывает, от чьего имени выполняются действия. При использовании root-доступа или Shizuku, запущенного от имени root, отключение и включение приложений, удаление и восстановление предустановленных приложений выполняются от имени root. Это позволяет Jiumi менять системные приложения, которые устройство запрещает менять пользователю shell. При беспроводной или сетевой отладке действия выполняются от имени пользователя shell. Если устройство блокирует изменение системного приложения, Jiumi показывает причину. Удаление приложения, которое вы установили, затрагивает только текущего пользователя. Копия в рабочем профиле или во втором пространстве остаётся установленной.

Основные компоненты системы защищены по умолчанию. Изменение компонента, от которого зависит телефон, может повлиять на работу системы. Перед таким изменением Jiumi показывает предупреждение.

## Как Jiumi видит фоновую активность без root-доступа?

При работе приложений Android предоставляет записи об использовании разрешений, таблицы соединений, системные трассировки и журналы событий. Монитор Jiumi считывает доступные системные сигналы от имени **пользователя shell**. Приложение упорядочивает их по правилам и сохраняет в базе данных на телефоне. Мониторинг не внедряет код в другие приложения. Отключение или удаление приложений, отзыв разрешений и блокировку доступа к сети нужно запускать самостоятельно в разделе управления приложениями.

<p align="center"><img src="../images/how-it-works.en.png" alt="Приложения генерируют системные сигналы Android. Монитор Jiumi считывает их от имени пользователя shell. Приложение упорядочивает и хранит записи на телефоне. Необязательная запись доменов принимает DNS-запросы через локальный VPN." width="900" /></p>

| Источник сигналов | Что может увидеть Jiumi |
| --- | --- |
| Записи об использовании разрешений (AppOps) | Какое приложение использовало разрешение и когда, а также историю, которую хранит Android. |
| Таблицы соединений | Адреса, к которым подключались приложения. По умолчанию данные считываются каждые пять секунд. |
| Системные трассировки (Perfetto) | Распознаваемые вызовы системных служб и трафик по каждому соединению, если система это поддерживает. |
| Журналы событий | Когда запустился процесс и какую причину запуска записал Android. |

### Четыре способа подключения

| Способ | Кому подходит | Первая настройка | После перезагрузки |
| --- | --- | --- | --- |
| **Беспроводная отладка** (рекомендуется) | Большинству телефонов, без root и компьютера | Подключиться к Wi-Fi и один раз ввести код на телефоне | Сопряжение сохраняется. Нужны включённые Wi-Fi и беспроводная отладка |
| **Сетевая отладка** | Телефонам с уже открытым портом ADB | Найти или ввести порт и при запросе разрешить в Android. Код не нужен | Телефон должен снова открыть порт |
| **Shizuku** | Тем, кто уже использует Shizuku | Запустить Shizuku и разрешить Jiumi | Shizuku должен работать |
| **Root** | Телефонам с root | Разрешить Jiumi в менеджере root | Работает, пока действует разрешение |

Во всех четырёх случаях монитор работает от имени пользователя shell. Только с root или Shizuku, запущенным от имени root, перечисленные выше действия управления выполняются от имени root.

> **Безопасность сетевой отладки:** Jiumi подключается только к локальному адресу телефона и не открывает порт за вас. Порт, открытый через `adb tcpip` или похожим способом, обычно доступен другим устройствам той же сети. Используйте его только в доверенных сетях, не принимайте незнакомые запросы отладки и закрывайте порт, когда он не нужен.

**Необязательная запись доменов** использует локальный VPN, чтобы принимать DNS-запросы и без изменений пересылать их DNS-серверам текущей сети. Остальной трафик идёт напрямую к получателю. Запись доменов занимает системный слот VPN. Запросы через собственный шифрованный DNS приложения или частный DNS-сервер, заданный именем хоста, могут не попадать в запись.

## Скачать и запустить мониторинг

1. На телефоне ARM64 с Android 11 или новее скачайте и установите APK со страницы [GitHub Releases](https://github.com/ybblab/Jiumi/releases/latest).
2. При первом запуске Jiumi выберите способ запуска. Для рекомендуемой беспроводной отладки подключитесь к Wi-Fi и следуйте подсказкам, чтобы разрешить уведомления и включить параметры разработчика. Введите в уведомлении Jiumi шестизначный код сопряжения, показанный системой. Если уведомление недоступно, нажмите “Can’t type in the notification?” на шаге 3 и введите код в режиме разделённого экрана, в маленьком окне или через плитку быстрых настроек. Если порт ADB уже открыт, можно выбрать и сетевую отладку.
3. На странице **Monitor** нажмите **Start monitoring**. Во время мониторинга отображается постоянное уведомление. Остановить мониторинг можно из уведомления или приложения.

  <a href="../images/pairing-tile.en.png"><img src="../images/pairing-tile.en.png" width="196" alt="Другие способы сопряжения: плитка быстрых настроек" /></a>

После перезагрузки телефона, обновления Jiumi или перебоя в работе службы отладки Jiumi пытается продолжить тот же сеанс, когда выбранное подключение доступно, и повторяет попытку при возвращении в приложение. Если в карточке отображается **Monitoring interrupted**, восстановите подключение и нажмите **Resume**. Время перерыва не включается в длительность мониторинга.

Если монитор остановился при сетевой отладке, Jiumi пробует последний использованный порт или заново ищет локальный, чтобы продолжить сеанс. Карточка сообщает, если порт не найден или нужно разрешение.

При беспроводной отладке дополнительно включённая отладка по USB помогает сохранить работу монитора, если Android отключит беспроводную отладку при потере Wi-Fi. **Settings › Connection › Backup connection** по умолчанию выключено и подходит только телефонам, где система уже предоставляет порт ADB, доступный лишь самому устройству. Jiumi проверяет и использует этот порт, не открывая нового. Подробности есть в [руководстве по настройке](https://jiumi.ybblab.com/en/download/).

## Конфиденциальность и ограничения

- **Записи хранятся на телефоне.** В Jiumi нет учётных записей, а записи мониторинга не выгружаются. Приложение может проверять обновления на GitHub. Если вы выберете обновление, Jiumi скачает APK и проверит его размер, контрольную сумму SHA-256 и подпись. Проверку обновлений можно отключить.
- **Записи описывают активность и соединения.** Jiumi может показать, что разрешение использовалось или что в доступе было отказано. Приложение не видит сообщения, пароли или содержимое сетевого трафика.
- **Полнота данных зависит от системы.** Короткие соединения могут завершиться между замерами, а такие действия, как прямое чтение файлов, могут не оставлять доступных сигналов. Статистика трафика по каждому соединению требует Android 14 или новее и поддержки со стороны системы. Jiumi опускает часть неподтверждённой активности, чтобы уменьшить число ложных сообщений.
- **Обзор и рейтинг считают по-разному.** Обзор дополняется счётчиками Android по интервалам, которые могут захватывать время до начала мониторинга. Рейтинг учитывает только отдельные записи Jiumi. Если сеанс длиннее 31 дня, обзор **Session** и уведомление учитывают лишь первый 31 день; используйте **30 days**.
- **Мониторинг увеличивает расход заряда.** Расход зависит от активности приложений. Когда мониторинг больше не нужен, остановите его из уведомления.
